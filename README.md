## 🌟 Executive Summary & Solution Architecture
**GradeIQ** is an advanced, AI-powered intelligence layer designed to sit alongside the existing **Honeywell Quality Control System (QCS) Machine Direction (MD) Multivariable Model Predictive Control (MPC)**. During paper grade transitions (auto grade/recipe changes), process variables interact dynamically, often leading to off-spec production, broke, and high stabilization losses. 

GradeIQ solves this through a **4-pillar AI strategy**:
1. **Proactive Off-Spec Risk Prediction (Ensemble ML):** Uses an Ensemble of **XGBoost, LightGBM, and Temporal LSTM features** to predict whether the core quality parameter—**Basis Weight**—is at risk of deviating **>2.5% from setpoint** up to 15 minutes before physical violation occurs.
2. **Explainable AI (XAI) & Rationale Guidance:** Integrates **SHAP (SHapley Additive exPlanations)** to provide junior operators with real-time, human-understandable explanations of *why* a specific parameter (e.g., steam pressure saturation or filler flow turbulence) is causing instability.
3. **Source-Tagged Setpoint Optimization:** Generates corrective setpoint recommendations for **Stock Flow, Filler Flow, Dryer Steam Pressures, and Machine Speed** to minimize stabilization time. Every single recommendation is explicitly tagged with its inference source (`[Historical Mining]`, `[Recipe Process Limits]`, `[New Correlation Discovery]`).
4. **Closed-Loop Human-in-the-Loop Feedback & Recalibration:** Features an interactive Operator Dashboard equipped with **Accept/Reject controls**. Every decision is logged with timestamps to continuously evaluate recommendation accuracy and adaptively retrain the model.

## 📂 Repository & Workspace Structure
- **`data_generator.py`**: Generates a realistic, highly correlated industrial paper mill dataset (`paper_mill_grade_change_data.csv`) featuring normal runs, transitions, edge-case latency, noise, and hidden parameter interactions.
- **`ml_pipeline_xai.py`**: The core ensemble machine learning model, hidden correlation discovery engine, SHAP explainer, and setpoint recommendation logic.
- **`dashboard.py`**: An interactive real-time Operator Dashboard (built with Gradio/Plotly) suitable for running locally or directly inside Google Colab.
- **`GradeIQ_Google_Colab_All_in_One.ipynb`**: A complete, self-contained Google Colab notebook containing dataset creation, training, exploratory charts, hidden correlation heatmaps, and the interactive dashboard in a single runnable notebook.
- **`generate_pdf_presentation.py`**: A dedicated presentation builder that programmatically creates the official 6-slide **SIH Idea Submission Presentation PDF** with premium styling, clean column layouts, embedded charts, and **zero text-over-image overlaps**.
